# AI Coding Agent Design & UI/UX Toolkit

Bộ sưu tập các tài nguyên, hướng dẫn thiết kế, thành phần giao diện và công cụ kiểm tra giúp AI coding agent tạo ra sản phẩm chỉn chu, chuyên nghiệp và có chiều sâu thẩm mỹ.

## 🛠️ AI Coding Agent Skills & Rules
* **[UI/UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)** - Hướng dẫn xây dựng giao diện web và ứng dụng chuyên nghiệp.
* **[Taste Skill](https://github.com/Leonxlnx/taste-skill)** - Định hướng thẩm mỹ, hình ảnh tham khảo và kiểm tra trên trình duyệt.
* **[Impeccable](https://github.com/pbakaus/impeccable)** - 24 lệnh và 61 quy tắc giúp phát hiện, cải thiện giao diện còn rập khuôn.
* **[Skills for Designers and Engineers](https://github.com/emilkowalski/skills)** - Bộ kỹ năng về hoạt ảnh và chi tiết giao diện.
* **[Hallmark](https://github.com/nutlope/hallmark)** - Chọn chủ đề thiết kế và kiểm tra giao diện qua 57 tiêu chí.
* **[GSAP Skills](https://github.com/greensock/gsap-skills)** - Hướng dẫn agent tạo hoạt ảnh và hiệu ứng cuộn bằng GSAP.

## 📐 Design Standards & Configuration
* **[Awesome DESIGN.md](https://github.com/VoltAgent/awesome-design-md)** - Các tệp thiết kế mẫu để giữ giao diện nhất quán.
* **[Google DESIGN.md](https://github.com/google-labs-code/design.md)** - Định dạng giúp agent hiểu hệ thống thiết kế của sản phẩm.

## 🎨 UI Components, Prototyping & Advanced Effects
* **[Open Design](https://github.com/nexu-io/open-design)** - Không gian thiết kế cục bộ cho prototype, website và slide.
* **[React Bits](https://github.com/DavidHDev/react-bits)** - Thư viện hơn 200 thành phần React có hiệu ứng chuyển động.
* **[Scroll World](https://github.com/oso95/scroll-world)** - Tạo landing page 3D với hiệu ứng cuộn xuyên qua các cảnh.
* **[Canvas UI](https://github.com/DavidHDev/canvas-ui)** - Hiệu ứng WebGL chạy trên HTML tương tác, giữ nguyên khả năng bấm và chọn nội dung.
